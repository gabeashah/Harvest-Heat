Harvest Heat 🚜🏁

A farm-themed 3D tractor racing game inspired by kart racers. Race five AI opponents around **Dairy Cow Motorway**, with drifting, power-ups, crossing cows, and plenty of farm scenery.

Built in a single HTML file using Canvas 2D to render a 3D world. All visuals and sounds are generated in code—no external assets or dependencies.

## Play

Open `index.html` in your browser. No installation needed. The game also supports on-screen touch controls.

## Controls

| Key | Action |
| --- | --- |
| WASD / Arrow keys | Accelerate, brake/reverse, and steer |
| Space while turning | Drift; release for a charged boost |
| E | Use boost or throw an item forward |
| Q | Use boost or throw an item backward |
| R | Recover onto the track |
| Esc / P | Pause or resume |
| M | Toggle sound |

## On the track

- Choose from four farmers and tractors, then race three laps.
- Collect fertilizer for a two-second boost that ignores mud slowdown.
- Throw hay bales to spin out rivals, or eggs that land as slippery traps.
- Steer through gaps between crossing cows and watch out for muddy shoulders.
- Enjoy apple orchards, cornfields, white picket fences, and cowboys chasing horses beside the circuit.
